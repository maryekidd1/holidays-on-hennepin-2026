# Holidays on Hennepin 2026: decorating catalog

A static web page where invited Uptown businesses pick decorations and craft supplies for their Holidays on Hennepin decorating grant. The committee buys and delivers everything.

- Orders go to a private Google Sheet. No order or contact data is stored in this repository.
- Not indexed by search engines.
- Item data: `items.json`, `presets.json`. Settings: `config.js`.
